Je inlogcode voor Cloxa

Typ deze code in Cloxa:

{{ .Token }}

Of klik op deze knop op het toestel waar je Cloxa gebruikt:

Inloggen

Deel deze code met niemand. Cloxa zal je er nooit om vragen, ook niet telefonisch.

De code is 10 minuten geldig. Heb je niets aangevraagd? Dan mag je deze e-mail negeren.
